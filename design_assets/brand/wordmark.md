# NumbCrunch wordmark

Generated with the built-in Imagegen tool. `wordmark_source.png` is the original
2181 × 721 transparent working image; `wordmark.png` is the 2125 × 472 app export.
The same export lives at `gameplay/src/main/res/drawable-nodpi/home_title.png`.
The Home fallback and Game title aspect ratios both use 2125 / 472.

The export trims the source to pixel bounds `(28, 111, 2153, 583)` (right and
bottom exclusive). This retains 12 pixels around the alpha > 1 bounds, including
the visible bevel and soft shadow. No artwork was repainted or stretched.

## Generation prompt

Create a production game title wordmark with the ONLY text exactly 'NumbCrunch'
(capital N and C, one word, no other text). Wide horizontal single-line
composition about 5.5:1 aspect ratio with tightly trimmed transparent margins,
at least 1800 pixels wide. A cozy, premium tactile wooden number-puzzle game
aesthetic. Chunky extra-bold rounded slab serif letters similar to a warm
classic board-game title, beautifully legible at small sizes. Glossy
cream-to-gold beveled letter faces (#FFF3DC highlights, #FFD36B, #F7C766 midtones,
#F29A1C lower edges), thick dark chocolate-brown outline (#3E2A1E), a bronze
dimensional lower extrusion (#8A4B12), subtle soft dark-brown drop shadow. All
letters have the same tall confident cap-height rhythm; lowercase letters large
and full. Perfect spelling NumbCrunch. Restrained warm dimensional polish, no
ornate swirls, no badge, no border, no additional tiles, no background scene, no
wood panel, no tagline, no icon, no underline. True transparent background
preserving alpha. Keep all edges and shadow entirely inside the canvas, leave a
narrow margin for safe crop. This is a standalone wordmark asset used on the
existing dark wood game background, not a full mockup.
